Student Academic Success Analysis
Overview

This project analyzes factors associated with student academic success using statistical techniques in R.

Objectives
Explore relationships between student characteristics and GPA
Identify significant predictors of academic performance
Visualize trends using charts and graphs
Tools
R
R Markdown
ggplot2
dplyr
Methods
Data Cleaning
Exploratory Data Analysis
Correlation Analysis
Multiple Linear Regression
Results

The analysis identified several variables that were strongly associated with academic performance and demonstrated how statistical modeling can be used to understand educational outcomes.
