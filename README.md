# Student Academic Success Analysis

## Overview
This project explores the factors that are most strongly associated with student academic success using statistical analysis in R. The goal was to identify which variables have the greatest impact on students' GPA through data cleaning, visualization, and regression modeling.

## Objectives
- Analyze relationships between student characteristics and academic performance.
- Identify the variables most strongly associated with GPA.
- Apply statistical techniques to support data-driven conclusions.
- Present findings through visualizations and an interactive HTML report.

## Tools & Technologies
- R
- R Markdown
- ggplot2
- dplyr

## Skills Demonstrated
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Correlation Analysis
- Multiple Linear Regression
- Statistical Interpretation
- Technical Reporting

## Project Files
- `Project1.Rmd` – Source code and analysis
- `Project1.html` – Interactive HTML report
- `README.md` – Project overview
- `Student_performance_data _.csv` - Student dataset

## Key Findings
The analysis identified several factors that were significantly associated with student GPA. Exploratory data analysis and multiple linear regression were used to evaluate the relationship between academic performance and student characteristics. The project demonstrates how statistical methods can be applied to extract meaningful insights from educational data.

## How to Run
1. Download the project files.
2. Open `Project1.Rmd` in RStudio.
3. Install the required packages if needed:
   ```r
   install.packages(c("ggplot2", "dplyr"))
   ```
4. Knit the R Markdown file to generate the HTML report.
